▼
部署指南：
1. 将本HTML文件部署到 Cloudflare Pages（免费、无限带宽）或 Vercel
2. 在Supabase Dashboard → Project Settings → API 中获取 URL 和 Anon Key
3. 更新上方配置后点击保存，刷新页面即可生效
4. 免费版限制：500MB数据库、50K月活用户、7天无活动暂停
